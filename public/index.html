Our API Details

Base URL: https://nepaldateconversionapi.vercel.app/api

Endpoints:

  • GET /api/today - Get today's Nepali date

  • GET /api/convert/ad-to-bs - Convert AD to BS

  • GET /api/convert/bs-to-ad - Convert BS to AD

Examples:

AD to BS: https://nepaldateconversionapi.vercel.app/api/ad-bs?date=2024-06-01

BS to AD: https://nepaldateconversionapi.vercel.app/api/bs-ad?date=2081-02-18



This API is useful for the conversion of Bikram Sambat (BS) dates to Gregorian (AD) dates and vice versa. It is important to note that Bikram Sambat (BS) calendar conversion cannot be performed using simple arithmetic, NepalDate relies on calendar data to provide accurate conversion results.

This API uses the @inicrea/bikram-sambat-core and @inicrea/nepali-calendar packages for date conversion and calendar information.
